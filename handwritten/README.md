# Handwritten Notes

This folder must contain **photos or scans of handwritten explanations** for each bug found.

## Required Content

For each bug (listed below), write a separate handwritten note on paper covering:
- Where the bug is (file name, line number, layer: frontend/backend/SQL)
- How you discovered it (code review, reading the query logic, etc.)
- What the root cause is
- How you fixed it and why you chose that approach

## Instructions

- Write each bug on a **separate sheet of paper** (or clearly separated sections)
- Photograph or scan clearly (good lighting, all text legible)
- Name your photos: `bug1.jpg`, `bug2.jpg`, `bug3.jpg`, `bug4.jpg`
- Add them to this `handwritten/` folder before pushing

> **Submissions without handwritten explanations will be considered incomplete.**
